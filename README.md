# 🏦 Système de Gestion Bancaire en Java

Une application console en Java permettant de gérer des comptes bancaires de manière dynamique.

Projet développé dans le cadre de mon apprentissage de la programmation orientée objet et des structures de données en Java.

---

## 🚀 Fonctionnalités

- **1. Création de compte :** Ajout dynamique d'un titulaire avec son solde initial.
- **2. Dépôt d'argent :** Crédit sur le compte.
- **3. Retrait d'argent :** Sélection dynamique du compte avec contrôle des bornes et vérification d'index.
- **4. Affichage des comptes :** Consultation de la liste globale des titulaires et de leurs soldes.
- **5. Quitter :** Fermeture sécurisée du programme.
